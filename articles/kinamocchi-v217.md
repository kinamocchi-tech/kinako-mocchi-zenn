## 1兆パラメータMoEの正体

- 🦜 きなこ：安心して、実は動くとき使ってるのはほんの一部だけなの
![MoEアーキテクチャ図解：総パラメータ1兆 vs 活性化パラメータ320億](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V217/013_cue.png)
- 🦜 きなこ：1兆のうち、実際に働くのは320億だけ。残りは待機してるの
![専門家ルーティングの模式図：384エキスパートから8つを動的選択](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V217/015_cue.png)
- 🦜 きなこ：近いね。384人の専門家がいて、問題ごとに8人だけが選ばれて答えるの。これがMixture of Expertsっていう仕組みなんだよ
- 🦜 きなこ：ちょっと違う。『必要な人だけ働く』が正確なの。だから1兆パラメータでも、計算コストは抑えられるんだよ
![必要ハードウェアの図解：ディスク約595GB・NVIDIA B200等サーバー級GPU](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V217/020_cue.png)
- 🦜 きなこ：そこは正直に言うね。フル精度だとディスクだけで約595GB必要で、NVIDIA B200みたいなサーバー級GPUが前提なの。普通のパソコンの話じゃないんだよ
![VRAM要件の比較：605GB→325GB（Unsloth Dynamic 2-bit量子化）](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V217/022_cue.png)
- 🦜 きなこ：そこまでじゃないよ。Unslothっていう会社が2ビット量子化っていう圧縮技術を使うと、必要な容量が約325GBまで下がるの。まだハイエンドだけど、選択肢は広がってるんだよ

## 『+21.8%』はどう作られた数字か

![自己採点のイメージを示す寓意的な図解（採点者と受験者が同一人物の構図）](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V217/037_cue.png)
- 🦜 きなこ：そう思うよね。でもその21.8%、実は身内の物差しで測った数字なの
![Kimi Code Bench v2の評価タスク領域の図解（10以上の言語・複数領域）](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V217/039_cue.png)
- 🦜 きなこ：Kimi Code Bench v2っていう、Moonshot自身が作ったテストなの
- 🦜 きなこ：バックエンド構築からセキュリティ、フロントエンドまで10以上の言語をカバーしてるんだけど、問題そのものも採点基準も非公開なの
- 🦜 きなこ：そこまでは言わないけど、テストの中身が見えないから、第三者が同じ条件で再現できないのは事実
![K2.6→K2.7のスコア推移グラフ（50.9→62.0）](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V217/044_cue.png)
- 🦜 きなこ：それがKimi Code Bench v2でのK2.6とK2.7のスコア。この条件下でだけ21.8%伸びたってこと
- 🦜 きなこ：意味がないわけじゃないよ。ちゃんとGPT-5.5やClaude Opus 4.8には届いてないって、自分たちで正直に公開してるところは評価できるの

## 独立ベンチに出てこない、という選択

![SWE-bench・Terminal-Bench運営元の紹介図解（第三者運営）](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V217/062_cue.png)
- 🦜 きなこ：どっちもMoonshot以外の第三者が運営してる、業界標準のテストなの。SWE-benchは実際のGitHubの課題を解けるかを見るテスト
![「未提出」を示す✕印付きベンチマークロゴ演出](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V217/064_cue.png)
- 🦜 きなこ：それがね、K2.7-Codeはこのどちらにも提出されてないの。公開されてる数字は全部Moonshot自身のテスト環境の結果
![過去の自社ベンチ誤算事例を示す概念イラスト](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V217/066_cue.png)
- 🦜 きなこ：実はこれ、業界で前にも似たことがあったの。自社ベンチで大勝利って発表したモデルが、独立の環境で試したら全然振るわなかったっていう
- 🦜 きなこ：モデルが、テストの傾向に合わせすぎて過学習しちゃうことがあるの。『練習問題を丸暗記した生徒』みたいな状態だね
![業界標準ベンチマーク比較表（Model/価格/コンテキスト/SWE-Bench/Terminal-Bench）](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V217/070_cue.png)
- 🦜 きなこ：参考までに、独立ベンチで比べるとこうなるの
![GPT-5.5・Claude Opus 4.8の独立ベンチスコア表示](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V217/071_cue.png)
- 🦜 きなこ：GPT-5.5はTerminal-Bench 2.0で82.7%、Claude Opus 4.8はSWE-bench Proで69.2%

- 🦜 きなこ：実は私も最初、この値段設定を見て二度見しちゃったの
![API価格比較表（Kimi K2.7-Code / GPT-5.5 / Claude Opus 4.8）](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V217/087_cue.png)
- 🦜 きなこ：入力100万トークンあたり0.95ドル、出力は4.00ドル。GPT-5.5は入力5ドル・出力30ドルだから、出力だとおよそ7分の1
- 🦜 きなこ：Claude Opus 4.8と比べても出力コストは約6分の1なの
![月間コストシミュレーション表（GPT-5.5/Claude Opus 4.8/Kimi K2.7-Code）](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V217/091_cue.png)
- 🦜 きなこ：自動化タスクで月1000万トークン出力すると仮定すると、GPT-5.5は月300ドル、Claude Opus 4.8は月250ドル
- 🦜 きなこ：Kimi K2.7-Codeなら月40ドルくらいで済んじゃうの

## 実機検証で見えた本当の実力

- 🦜 きなこ：その質問、みんな聞きたいと思う。でも答えは『用途による』なの
![Composio実機検証の紹介図解（出典クレジット表示）](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V217/114_cue.png)
- 🦜 きなこ：逃げてないよ。AIツール連携企業のComposioが、Terminal-Bench 2.0の一番難しい10タスクで、K2.7-CodeとMiniMax M3を比べたの
![Composio実機検証結果の図解（出典クレジット表示）](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V217/116_cue.png)
- 🦜 きなこ：10問中5問正解で同点タイ。でもコストはKimiが5.86ドル、MiniMaxが2.80ドルで、Kimiの方が2.1倍高くついたの
![TTFT（応答までの待ち時間）比較のイメージ図解](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V217/118_cue.png)
- 🦜 きなこ：そう。それに『考える』モードが常にオンだから、返事が来るまで少し時間がかかるの。だから入力補完みたいな一瞬の反応が必要な場面には向いてない
- 🦜 きなこ：友達に質問したとき、パッと即答してくれる友達と、ちょっと考えてから丁寧に答えてくれる友達がいるとするよね
- 🦜 きなこ：前者はチャットの合いの手向き、後者はじっくり任せる相談向き。K2.7-Codeは完全に後者タイプなの
