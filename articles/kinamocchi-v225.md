## なぜ端末の中で動かすのか — Tensor G5 の意味

![端末内のNPUが並列計算をまとめて処理し、クラウドへ送信せずその場で結果を返す流れ図。図中テキストは英語で『On-device NPU』『No data leaves the device』『Zero network latency』](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V225/030_cue.png)
- 🦜 きなこ：そこなの。NPUっていうAI専用の回路が大きな計算を低い電力でさばくから、データを外に送らないまま、その場で答えが返せるんだよ
![前世代チップと Tensor G5 の性能を並べた横棒グラフ。図中テキストは英語で『Tensor G5 / TSMC 3nm』『TPU: up to +60%』『CPU: +34%』](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V225/032_cue.png)
- 🦜 きなこ：その例え、いい線いってるの。支えてるのがPixel 10に載ったTensor G5。3ナノメートル世代で、TPUが最大60%、CPUも34%速くなったの
![オンデバイス動作を示す指標カード2枚が並ぶ図。図中テキストは英語で『Gemini Nano: fully on-device』『Speed: 2.6x』『Power efficiency: 2x』](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V225/034_cue.png)
- 🦜 きなこ：そう。このTensor G5のおかげでGemini Nanoが端末の中だけで動くようになって、処理速度は2.6倍、電力効率は2倍まで上がったんだよ
- 🦜 きなこ：そこは少し違うの。同じ処理に必要な電力がだいたい半分で済むって意味なんだよ。持ち時間がそのまま倍になるわけじゃないの
![端末側とクラウド側で処理を振り分けるハイブリッド構造図。左に軽量処理、右に重い動画生成を配置。図中テキストは英語で『On-device: Gemini Nano』『Cloud: Veo 3 / Gemini Omni』](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V225/038_cue.png)
- 🦜 きなこ：そこはちゃんと線が引かれてるの。ゼロから作る重い動画生成は今もクラウド側のVeo 3やGemini Omniに投げて、端末は軽い処理を持つ形なんだよ
![端末側へ処理を寄せる矢印と、クラウド計算コストの棒グラフを1本の線で結ぶ図。図中テキストは英語で『On-device shift』『Cloud compute cost』](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V225/040_cue.png)
- 🦜 きなこ：その分け方こそが大事なの。この『わざわざ端末の中でやる』っていう選び方が、さっきのSoraの話と一本の線でつながってるんだよ

## Soraが消えた日 — 計算コストという現実

![敗因の対比図（技術面と採算面を左右に並べる）。図中テキストは英語で『Not beaten by technology — beaten by unit economics』](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V225/041_cue.png)
- 🦜 きなこ：正直に言うとね、Soraが終わるって最初に聞いたとき、私も技術で追い抜かれたんだと思ってたの。でも原因は全然そこじゃなかったんだよ
- 🦜 きなこ：違ったの。品質でも規制でもないの。一番の理由として報じられてるのは、サーバーの計算コストなんだよ
![終了スケジュールのタイムライン図（発表→アプリ終了→API終了）。図中テキストは英語で『Mar 24, 2026: announced / Apr 26, 2026: consumer app ends / Sep 24, 2026: developer API ends』](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V225/044_cue.png)
- 🦜 きなこ：一般向けアプリは2026年4月26日、開発者向けAPIは2026年9月24日。発表と同時に、店じまいの日付まで先に決まってたんだよ
![動画1本の生成に必要なGPU稼働を示す内訳図。図中テキストは英語で『1 clip = 10s @ 1080p → 4x NVIDIA H100 → 8-10 min at full load』](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V225/046_cue.png)
- 🦜 きなこ：かかるの。10秒の1080p動画を1本作るのに、H100っていう高性能なGPUを4基、8分から10分ずっとフル稼働させる必要があったの
![1本あたりのコストが積み上がっていく棒グラフ図解。図中テキストは英語で『Cost per 10s clip: about $1.30』](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V225/048_cue.png)
- 🦜 きなこ：その積み上げで、動画1本あたりの生成単価が約1.30ドル。誰かが1本作るたびに、その分がまるごと持ち出しになっていく計算なんだよ
![クラウド集中とオンデバイス分散のコスト構造を左右で比較した図。図中テキストは英語で『Cloud: pay per generation / On-device: no per-run server cost』](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V225/051_cue.png)
- 🦜 きなこ：そのたとえで合ってるの。Googleが軽い処理を端末の中へ逃がしてるのも、この出ていく分をそもそも発生させないための逃げ道なんだよ

## 2026年の勢力図 — 3つの生き残り方

- 🦜 きなこ：もっちーの今の問い、置き換えると一気に見えるの。どれが一番きれいか、じゃなくて、どこなら元が取れるか。そう聞くと答えは三つに割れるんだよ
![3モデルの比較テーブルを表示。図中テキストは英語で『Veo 3 / Kling 3.0 / Runway Gen-4.5』と列見出し『Cost / Length / Audio / Control』](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V225/058_cue.png)
- 🦜 きなこ：残ったのはVeo 3にKling 3.0、それとRunway Gen-4.5。どれが最強かじゃなくて、どれをどこで使うかの話に変わったの
![映像と音声が同一パスで生成される流れ図。図中テキストは英語で『Video + native audio in one pass』](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V225/059_cue.png)
- 🦜 きなこ：Veo 3は映像を作ってから音を足すんじゃないの。環境音もセリフに合わせた口の動きも同じ流れで一度に作る。ここに最初に対応したモデルなんだよ
![単価カードを表示。図中テキストは英語で『Veo 3: about $0.75 / sec — 8 sec is about $6.00, max 8 sec per prompt』](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V225/061_cue.png)

![Kling 3.0 のスペックカード。図中テキストは英語で『about $0.075-$0.168 / sec, up to 2 min, native audio, 4K/60fps』](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V225/062_cue.png)
- 🦜 きなこ：Kling 3.0は真逆の攻め方なの。1秒あたり約0.075から0.168ドルの最安クラスで、こっちも音つき。標準は15秒、長ければ2分まで出せるんだよ
- 🦜 きなこ：もっちー向きかもね。写真一枚から動かす忠実度も高くて量産向き。そのかわり、動きを一つずつ細かく指定する方向は得意分野じゃないの

## 作った動画は誰のものか — 権利の落とし穴

- 🦜 きなこ：ここね、白状すると私も長いこと勘違いしてたの。AIで作った動画は当然作った人のもの、って一度も疑ってなかった。けっこうな落とし穴だったの
![AI丸投げの生成物には著作権が発生しないことを示すカード。図中テキストは英語で『AI-only output = No copyright』](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V225/087_cue.png)
- 🦜 きなこ：でもね、いま実務では、AIに丸投げして生成しただけの映像や画像には、そもそも著作権が発生しないって整理されてるの。本人にも権利が残らないの
- 🦜 きなこ：落ち着いて、もっちー。ここ、線の引き方が大事なの。否定されたのはAI単独で生成したものの著作権で、人の創造的な関与がある作品は対象外なんだよ
![判決タイムライン。図中テキストは英語で『Mar 2, 2026 — US Supreme Court denies review (Thaler v. Perlmutter)』](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V225/090_cue.png)
- 🦜 きなこ：事実だけ先に言うね。米最高裁が2026年3月2日、AIだけで自律的に生成したアートワークの著作権登録を求める訴えの上告を、棄却したの
- 🦜 きなこ：そう。これで、著作権が守られるには人間の著作者が必要だっていう判断が、アメリカでは確定したことになったの。AI単独ではダメってこと
![AIへの丸投げと人間の関与ありを分ける二分岐図。図中テキストは英語で『Prompt only: no copyright, no remedy』『Human creative input: protectable』](https://pub-2687e67855c941a0a1a9e1ad51ffc967.r2.dev/images/V225/094_cue.png)
